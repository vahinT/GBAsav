How to use this program.

You must open your app, use the ingame save option, and then save a state in a new state slot, **DONT USE ONE WHICH IS ALREADY FILLED**, Then go into the files app on your phone > internal storage > Android > data > (search for something that has "emulator" in it) > files > the .state_1 file, if your slot is number 2, then the .state file will be .state_1, basically substract one from your slot number to get the file extension. copy that, put it on your laptop and open command prompt. Open your downloads directory, or wherever you kept the file. type "python savext.py extract (.state_1) (.sav)". And thats it.
